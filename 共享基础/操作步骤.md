# 黑猫投诉爬虫 · 详细操作步骤手册（API 版）

> 适用：Windows 电脑，需联网。
> 黑猫投诉是动态站，数据在**带签名的 JSON 接口**里，脚本已内置签名算法（来自开源项目 yeyeye777/toususina）。
> 顺序：**装环境 → --inspect 看字段 → 小批量验证 → 全量挂机 → 检查 → 共享**。

---

## 第 0 步：准备（一次性）

1. 找台能上网的 Windows 电脑；
2. 安装 uv：
   ```cmd
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```
   装完**重开终端**，`uv --version` 有版本即成功；
3. 拿到项目文件夹 `hemao_scraper`。

## 第 1 步：配置环境

```cmd
cd hemao_scraper
uv sync
```
只装 1 个依赖（requests），很快。验证：`uv run python scraper.py --help`。

## 第 2 步：--inspect 看接口字段（务必先做！）

```cmd
uv run python scraper.py --inspect
```
输出应包含：
- `main 字段清单`（title/summary/cotitle/appeal/issue/...）
- 样例 title/cotitle/issue
- 样例 JSON 已存 `data\debug\feed_sample.json`

**看两点**：① 接口通不通；② 有没有 `industry/category` 类字段（有 → 自动进 `category` 列；没有 → 用 `issue` 当分类标签）。

> 失败排查：确认联网；电脑时间是否准确（签名依赖时间戳）；换 `--type` 值试探。

## 第 3 步：小批量验证

```cmd
uv run python scraper.py --max-items 500
```
打开 `data\hemao_complaints.csv`：id/title/summary/cotitle/issue 有内容、无乱码 → 继续。

## 第 4 步：正式全量爬（推荐 5万条）

```cmd
uv run python scraper.py --max-items 50000
```
或双击 `run.bat`（透传参数）。想快：`uv run python scraper.py --delay 0.4 --max-items 50000`。

> 5万条约 1.5 小时（--delay 1）；10万约 3 小时。嫌慢就用 API 优势，**不用多机分片了**。

## 第 5 步：挂机设置

- 电源设为"从不睡眠"、保持联网；
- 中断不可怕：`--resume` 续爬（自动跳过已抓 id、从断点页继续）。

## 第 6 步：中断/被限流

```cmd
uv run python scraper.py --resume --max-items 50000
```
- 连续 403/429 = 被限流：停 2~4 小时或换网络 → `--resume` 并降低 `--delay`；
- `--resume` 时参数（尤其 `--max-items`）和上次一致。

## 第 7 步：数据质量检查

PowerShell：
```powershell
# 行数
(Import-Csv data\hemao_complaints.csv).Count
# issue 分布（当标签用的话看均衡性）
Import-Csv data\hemao_complaints.csv | Group-Object issue | Sort-Object Count -Descending | Select-Object Count, Name
```
抽查 20 条 summary/issue 是否完整。

## 第 8 步：共享与收尾

- `data\hemao_complaints.csv` 传**群文件/网盘**，**不要进 Git**（已 .gitignore）；
- 删掉 `data\debug\`；保留 `data\progress.json`（补数据用）；
- 把"爬了多少条、issue/category 分布、踩的坑"写进日报。

## 常见问题速查

| 现象 | 原因/处理 |
|---|---|
| `uv 不是内部或外部命令` | 装完没重开终端 |
| `--inspect` 接口失败/空 | 本机联网；时间不准会签名失败；`--type` 换值试 |
| CSV 打开乱码 | 用 Excel/记事本/VSCode（文件是 UTF-8-BOM） |
| category 列为空 | 接口无行业字段 → 用 `issue` 当标签，或后期补爬详情页 |
| 连续 403/429 | 被限流 → 停几小时或换网络 → 降速续爬 |
| 电脑睡着中断 | 电源设从不睡眠；`--resume` 续爬 |
