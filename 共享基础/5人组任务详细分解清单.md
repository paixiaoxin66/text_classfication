## 三、成员C：随机森林 / FastText 基线指标（算法工程师·基线）

### 3.1 现有基础（仓库已具备）
- `train_baseline.py`：TF-IDF + 朴素贝叶斯/逻辑回归（默认分词，acc 仅 22.46%，是"坏基线"素材）
- `scripts/train_baseline_ablation.py`：NB/LR/SVM × R纯真实/A纯增强/M混合 三配置消融
- 关键结论：**字符2-4gram + 线性SVM = 79.70% acc / macro-F1 0.7587**（当前最强传统基线）
- ⚠️ **随机森林、FastText 均未实现**（pyproject 无 fasttext 依赖）→ 本轮核心新增工作

### 3.2 详细任务清单
1. ⬜ **新增随机森林基线**：`train_rf.py`，TF-IDF(char_wb) + `RandomForestClassifier`（n_estimators=200~500、max_depth 调参、n_jobs=-1），与 SVM/LR 同数据、同验证集选优，输出报告+混淆矩阵到 `data/out_baseline_rf/`。
2. ⬜ **新增 FastText 基线**：`uv add fasttext`（Windows 可用 fasttext-wheel），训练 supervised 分类（默认参数 + lr/epoch 微调），输出 `data/out_baseline_fasttext/` 报告 + 模型.bin。
3. ✅ 复用消融脚本跑增强前后对比（答辩核心论据）：R(6893) vs A(23107) vs M(30000)，`--tokenizer char_wb`。
4. ⬜ **产出多模型对比总表** `data/reports/model_comparison.md`（统一 Test 877 真实数据）：
   | 模型 | 准确率 | macro-F1 | 训练时长 | 模型体积 |
   |---|---|---|---|---|
   | 朴素贝叶斯(默认分词) | 22.46% | 0.1934 | ~秒级 | — |
   | 逻辑回归(char_wb) | 78.56% | 0.7476 | ~分钟 | KB级 |
   | 线性SVM(char_wb) | 79.70% | 0.7587 | ~分钟 | KB级 |
   | 随机森林(char_wb) | ⬜待跑 | ⬜ | ⬜ | ⬜ |
   | FastText | ⬜待跑 | ⬜ | ⬜ | ⬜ |
   | BERT | 85.40% | 0.8443 | GPU 10~20min | 409MB |
5. ⬜ 把基线模型保存为 joblib 供成员E演示兜底：`data/out/baseline.joblib`（含 vectorizer+model+labels，支持 `--demo "文本"` 单条预测）。
6. **验收标准**：随机森林 + FastText 指标进入对比总表，结论可答辩（"传统基线 79.7% → BERT 85.4%，深度学习 +5.7 点"）。

## 四、成员D：BERT 最优模型 + 剪枝/蒸馏/量化对比（算法工程师·深度+优化）

### 4.1 现有基础（仓库已具备）
- `train_bert.py`：bert-base-chinese 微调（自动检测 GPU/CPU、warmup、早停）
- 产物：`data/out/bert_model/`（model.safetensors **409MB**）、`bert_report.txt`（**acc 85.40% / macro-F1 0.8443**）、`bert_confusion.png`、`label_map.json`
- ⚠️ **剪枝、蒸馏、量化均未实现**（文档只列了计划）→ 本轮核心新增工作

### 4.2 详细任务清单
1. ✅ 复现 BERT 微调并记录环境：`uv run python train_bert.py --epochs 3 --batch-size 32`（GPU 10~20min / CPU 2~4h），记录设备、耗时、显存。
2. ⬜ **调优记录**（评分五要求）：学习率（2e-5 vs 3e-5 vs 5e-5）、epochs、batch-size、早停轮次 → 整理成 `data/out/bert_tuning_log.md`；做**薄弱类分析**：电商平台(0.62)、影音娱乐(0.72)、母婴食品(0.40，仅6条支撑)的原因与对策。
3. ⬜ **剪枝**：`optimize/prune_bert.py`，`torch.nn.utils.prune` L1 非结构化 30%，剪后重评估，输出稀疏度/体积/指标变化。
4. ⬜ **蒸馏**：`optimize/distill_bert.py`，BERT(teacher) → BiGRU 或 DistilBERT(student)，软标签 KL 蒸馏，输出学生模型 + 指标。
5. ⬜ **量化**：`optimize/quantize_bert.py`，动态 INT8 量化（`torch.quantization`）或 **ONNX 导出** + onnxruntime 推理，测推理加速比。
6. ⬜ **产出"压缩前后对比表"** `data/out/optimization_report.md`：
   | 版本 | 体积 | 推理延迟(单条) | 准确率 | macro-F1 |
   |---|---|---|---|---|
   | BERT 原版(FP32) | 409MB | ⬜ | 85.40% | 0.8443 |
   | 剪枝30% | ⬜ | ⬜ | ⬜ | ⬜ |
   | 蒸馏后学生模型 | ⬜ | ⬜ | ⬜ | ⬜ |
   | INT8量化/ONNX | ⬜ | ⬜ | ⬜ | ⬜ |
7. **验收标准**：三个优化版本至少完成两个并出对比表（答辩评分九"模型压缩优化"直接对应）；被压缩模型交给成员E部署。
